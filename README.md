# エアラインコネクト

日本の国内線を舞台にした、航空会社の経営ゲーム（開発中）。

**飛ばない空を見つけ、そこに線を引け。** 空白になっている区間を見つけて結ぶのが、このゲームの
いちばんの面白さです。リアルさよりも、コミカルさ・手軽さ・遊びやすさを優先しています。

## 遊ぶ

`prototype/play.html` をブラウザで開くだけで遊べます（1枚のHTMLで完結しています）。

初めてなら、タイトルの **🎓 はじめての1年** を選ぶと、
空港えらびから2本目の路線をひくまで、20手順の案内が付きます。

ローカルサーバーで開きたいときは：

```bash
node prototype/server.cjs
```

## 中身

| 場所 | 中身 |
|---|---|
| `prototype/play.html` | 本体。HTML・CSS・JavaScript が1枚に入っています |
| `prototype/db/` | 空港と人口のSQLite（`node prototype/db/seed-airports.cjs` で作り直せます） |
| `airline-management/` | Next.js版の試作（現在は `play.html` の方で作っています） |
| `国際線構想メモ.md` | 開発メモ。直した理由と、やってみて駄目だった案が日付順に入っています |
| `企画書.txt` | 最初の企画書 |

## 作りの決まりごと

- **1枚のHTML**。ビルドの手順を増やさず、開けばすぐ動く状態を保つ。
- **直した理由を残す**。コード中のコメントと `国際線構想メモ.md` に、
  「なぜそうしたか」と「試して駄目だった形」を書き足していく。
- **操作しているあいだ、画面が動かない**。押すたびに枠が伸びたり、
  吹き出しが消えて出てきたりしないようにする。
